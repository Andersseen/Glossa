# Roadmap

## 0.1 Foundation

Project structure, Analog SSR/API configuration, Cloudflare Pages/D1 preparation, UI shell, testing, linting, formatting, CI, and docs.

## 0.2 Projects and Catalogs

Create project records, locales, JSON catalogs, and Glossa-owned API routes for basic project/catalog operations.

## 0.3 Translation Editor and Completeness

Build the translation editing workflow, missing-key detection, and completeness summaries.

## 0.4 Project API and API Tokens

Add project-scoped API tokens and JSON catalog distribution endpoints.

## 0.5 External Dogfooding

Use Glossa with real software projects, refine API ergonomics, and harden operational workflows.
